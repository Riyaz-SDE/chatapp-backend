# Notification Server

A Node.js server using Express and Socket.IO to create, store,
and deliver real-time user notifications.

## Tech Stack

- Node.js
- Express
- Socket.IO
- JavaScript
- In-memory Map database

## Features

- Create notifications
- Store notifications per user
- Retrieve user notifications
- Real-time notification delivery using Socket.IO
- User-specific Socket.IO rooms
